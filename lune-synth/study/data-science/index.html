Lune Synth for Data Science

Trace the code, read the matrix, defend the metric.

Data science courses test the same model-evaluation ideas repeatedly: compute precision and recall from a confusion matrix, trace what a loop actually returns, read whether a scatter plot supports the correlation someone claimed. Lune Synth sets up the matrix or the code and checks your calculation, not just whether you picked the right multiple-choice label.

Where data science students get stuck

Naming precision and recall isn't the same as computing them under pressure.

Students can define precision, recall and F1 and still swap the numerator and denominator under a real confusion matrix, or misread a loop's final value by one iteration. Computing the metric from the matrix, and tracing the code line by line, is the skill the exam and the take-home test.
