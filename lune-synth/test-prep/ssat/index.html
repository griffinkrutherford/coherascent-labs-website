An admissions test, not a punishment

A missed SSAT question should point to a skill, not a verdict on the student.

The SSAT asks students to work quickly across quantitative and verbal sections at once, and a wrong answer can come from a rushed calculation, a misread question, or a genuine gap. Lune Synth reads the written attempt so a family can see exactly which skill needs another pass, with feedback that stays encouraging.

Quantitative attempt

What grading notices

The multiplication in each column is correct. The carried digit needs to be added back in before moving to the next place value.

Luna's hint

You carried a 4 from the ones column. Where does that 4 need to be added next?
