CLEP College Algebra attempt

The system y > x - 1 and y ≤ -x/2 + 4 is set up correctly, but the point (4, 4) is tested against the strict inequality as if it were allowed on the boundary.

What grading notices

Your substitution is correct. The boundary line in the first inequality is dashed, so a point exactly on it does not count as a solution.

Luna's hint

Which of the two boundary lines is solid, and which is dashed? Only the solid one includes its own line.
